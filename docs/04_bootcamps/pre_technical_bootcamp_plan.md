# Pre-Technical Bootcamps: Programme Plan

**Window:** 7–9 Dec 2026 (3 days, virtual; recorded), aligned with technical bootcamp and mentor matching. Kickoff on 25 Nov shares the orientation session (Bootcamp 0).
**Format:** 2.5-3 hrs/day live + office hours. Target cohort: 40-100 selected participants. Sessions run in parallel where marked.

## Bootcamp 0: Orientation (25 Nov, 90 min, all)

Programme rules, tracks, code of conduct, tools, how to submit, live repo/notebook tour.

## Bootcamp 1: Foundations (7 Dec, all)

| Time   | Session                                                                        | Output                             |
| ------ | ------------------------------------------------------------------------------ | ---------------------------------- |
| 60 min | Electoral process for technologists (guest: electoral practitioner / observer) | Process map                        |
| 45 min | Responsible AI, privacy and Nigeria Data Protection Act essentials             | Harm/benefit table                 |
| 60 min | Repo, environment and data pack walkthrough                                    | Team repo forked, notebook running |

## Bootcamp 2: Applied ML and evaluation (8 Dec, tracks 1,2,3,5)

Baselines, leakage, metrics, per-group evaluation, abstention/calibration. Lab: improve and stress-test `notebooks/01` or `02`.

## Bootcamp 3: NLP and multilingual AI (8 Dec, tracks 1,3,5)

Retrieval, embeddings, RAG with citations, low-resource language strategies, working with native-speaker reviewers. Lab: extend `notebooks/03`; produce a per-language evaluation table.

## Bootcamp 4: Security, privacy, data quality (8 Dec parallel, tracks 2,4)

STRIDE workshop, safe practice environments, k-anonymity, tamper-evident logs, anomaly explainability. Lab: `notebooks/05` and a threat model for your idea.

## Bootcamp 5: Inclusive and low-bandwidth product design (9 Dec, tracks 3,5 + all)

WCAG quick audit, screen reader demo, offline-first, SMS/USSD constraints, usability testing with real users (consent, ethics). Lab: audit and fix one interface.

## Bootcamp 6: Ship it (9 Dec, all)

Docs templates (README, model card, safety), demo scripting, MVP scoping for the prototype development sprint, judging rubric walkthrough, mentor matching finalisation. Output: one-page sprint plan with milestones for 11-21 Dec.

## Facilitator kit

Slides, lab notebooks, answer keys (organisers only), attendance tracker, feedback form. Speakers: partner AI experts, electoral subject-matter experts, accessibility specialists, data-protection lawyer.

## Success measures

Attendance >= 80% of sessions per team; 100% of teams with a running notebook and repo by 9 Dec; post-bootcamp confidence survey; sprint plan submitted.

## Logistics checklist

Meeting platform with captions and recording; data-light option (audio + slides); time slots suited to WAT; low-bandwidth materials pre-shared; sign-in for certificates.
