# Datasheet: <dataset name>

1. **Motivation:** why created, by whom, funded by.
2. **Composition:** what each record is, counts, fields (attach data dictionary), label definitions, class balance, missing data. Is it synthetic, public, or authorised? Any personal or sensitive data? (Answer must be no or explain lawful basis and safeguards.)
3. **Collection process:** sources, sampling, tools, time frame, consent, permissions and licences.
4. **Preprocessing:** cleaning, anonymisation, aggregation, suppression thresholds, tools used.
5. **Uses:** intended tasks; tasks it must not be used for.
6. **Distribution:** licence, access, hosting, versioning, checksums.
7. **Maintenance:** owner, update schedule, how to report errors, retention/deletion.
8. **Known limitations and biases:** coverage by language, region, gender, disability; synthetic-data artefacts.
